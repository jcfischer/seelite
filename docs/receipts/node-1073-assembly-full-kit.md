support links, shared by drawing and collision. `createAssemblyBlocks` creates
one InstancedMesh per block/material, with shared geometry, materials and
textures. Each station owns only its instance matrices and sim-owned fittings.

procedural pruning has been removed.

`trade/d` uses the existing model catalog, boot requirements, serial queue,
settled predicate and station refresh. A home Assembly follows the existing
home-exterior boot contract. Elsewhere, download completion installs the
builder and the live station refresh replaces the stand-in once. Queue failure
is terminal for that session and warns once; jumping does not wait. The existing
refresh path reads the live system, preserves spinner phase and releases the
old root. The postcard's required model set includes this catalog entry.

Headless tests read actual batch matrices, exercise repeated station builds
and watch disposal events: shared resources survive another station's teardown,
and each old InstancedMesh is disposed. Material emissives are normalized to
`EMISSIVE_CEILING`, using the same rule as other authored exteriors.

## Collision and geometric checks

The existing part fitter produces one reusable fitted proxy table per block,
including LINK and HUB_STATIC. `assembly-proxies.ts` pins the shipping GLB hash.
Independent checks decode the shipping GLB through GLTFLoader/Meshopt and
measure written proxy faces on the fitter's 1 m grid with its margin inside
10 m; vertices outside the sim-owned opening lie within 1 m of their block
proxy. The fitted box counts are HUB 1,183; HUB_STATIC 96; NODE 397; TUBE 318;
TRUSS 99; RADIATOR 95; TANKS 261; DISH 166; LINK 55.

The hub fit disables the shared fitter's front-plane relocation exception:
this hub's face is recessed and does not use that exception's adapter. Static
cells retain the existing swept-bay keep-out. Oriented boxes intersecting its
boundary are recursively subdivided; intersecting residual boxes with all
half-extents ≤1 m are removed. This only removes collision within a strip at most
2√3 m outside the keep-out boundary; a thin part in that strip can be removed
entirely, so this is not a bound on distance to the nearest surviving box.
No fitted box is grown by that operation. Bay-wall collision
continues to come from the interior catalogue.

The 12-seed proxy corpus holds reach, vertex coverage and both rotating/static
opening checks. The thinnest primitive is 0.8 m. Production geometry checks use
the full regression seed spread plus 47, 1234 and 99, with hub phases 0°, 45°
and 90°; they measure actual instance transforms and triangles, aperture rays,
the corridor and the 1.0 km reach. The inherited spike joint rays and capture
seeds remain in place.
