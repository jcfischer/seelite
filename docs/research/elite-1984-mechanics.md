## Question

What exactly made Elite (1984) work, mechanically — seed scheme, market model, combat/progression,
docking — and what did faithful remakes (Oolite, Pioneer) change? Produce a reference that seelite's
design decisions can be built on.

## 1. Procedural galaxy generation

### 1.1 The seed

The whole universe derives from a **48-bit seed held as three 16-bit words** `w0, w1, w2`
(`seedtype` in txtelite.c). Galaxy 1's base seed is hard-coded:

```
w0 = 0x5A4A   w1 = 0x0248   w2 = 0xB753
```

Two operations drive everything:

**`tweakseed` — the Fibonacci-like twist (per-system step):**

```c
temp = w0 + w1 + w2;   /* 16-bit arithmetic, overflow wraps */
w0 = w1;  w1 = w2;  w2 = temp;
```

This is a Tribonacci-style lagged additive generator over 16-bit words. It is called **exactly four
times per system** (once per name digram drawn, see 1.4), so system N's record is a pure function of
the base seed — the galaxy is generated by iterating `makesystem` 256 times from the galaxy seed.
The original game regenerated data on demand rather than storing the galaxy ("Original game
generated from scratch each time info needed" — txtelite.c `buildgalaxy`).

**`twist` — the galactic-hyperdrive rotation (per-galaxy step):**

```c
rotatel(x)  = ((x & 127) << 1) | (x >> 7)      /* rotate one byte left */
twist(w)    = 256*rotatel(w >> 8) + rotatel(w & 255)
nextgalaxy(s) = { w0=twist(w0); w1=twist(w1); w2=twist(w2); }
```

Each byte of the seed is rotated left one bit. Applied once per galactic hyperdrive jump; the
**eighth application returns the base seed**, hence exactly **8 galaxies × 256 systems = 2048
systems** from 6 bytes of data.

### 1.2 The system record

`makesystem` derives everything from the seed *before* the four tweaks (bit-harvesting, not
arithmetic randomness):

| Field | Formula (txtelite.c) | Range / notes |
|---|---|---|
| x | `w1 >> 8` | 0–255 (galactic chart is a 256×256 byte grid) |
| y | `w0 >> 8` | 0–255 |
| government | `(w1 >> 3) & 7` | 0 Anarchy … 7 Corporate State |
| economy | `(w0 >> 8) & 7`; **if gov ≤ 1 then `economy \|= 2`** | 0 Rich Industrial … 7 Poor Agricultural. The OR forces Anarchy/Feudal systems away from rich economies (they can only be 2,3,6,7) |
| tech level | `((w1>>8)&3) + (economy ^ 7) + (gov>>1) + (gov&1 ? 1 : 0)` | 0–14 internal, **displayed +1** (so "TL 1–15"). Richer economy and stabler government ⇒ higher tech |
| population | `4*techlev + economy + gov + 1` | one byte; txtelite prints `population >> 3` as "N Billion" |
| productivity (GDP) | `((economy^7)+3) * (gov+4) * population * 8` | shown as "Turnover" in MCr |
| radius | `256*(((w2>>8)&15)+11) + x` | km; "not used by game at all" per the source comment |
| goatsoup seed | bytes of w1, w2 | seeds the "goat soup" grammar that generates the planet description text ("Lave is most famous for its vast rain forests…") |

Names for the categories (exact strings): governments `Anarchy, Feudal, Multi-gov, Dictatorship,
Communist, Confederacy, Democracy, Corporate State`; economies `Rich Ind, Average Ind, Poor Ind,
Mainly Ind, Mainly Agri, Rich Agri, Average Agri, Poor Agri`.

Note the interlock: economy, government, tech, population and GDP are **correlated, not
independent** — this is why the universe feels coherent. Anarchy ⇒ poorer economy ⇒ lower tech ⇒
smaller population, and (see §2) cheap agricultural goods plus danger. One 3-bit field cascades
into the whole gameplay profile of a system.

### 1.3 Distance and fuel

```c
distance = ftoi(4 * sqrt((dx*dx) + (dy*dy)/4));   /* in 0.1 LY units */
```

The y-axis is compressed 2:1 (the chart is drawn wider than tall). Fuel tank = **7.0 LY**
(`maxfuel = 70`), fuel cost **0.2 Cr / LY** (`fuelcost = 2` per 0.1 LY). The 7 LY radius is the
core pacing constraint: it defines reachability neighbourhoods and forces multi-hop routes.

### 1.4 Name generation

Names are built from a **32-entry digram table**:

```
"ABOUSEITILETSTONLONUTHNO" + "..LEXEGEZACEBISO" "USESARMAINDIREA."
"ERATENBERALAVETI" "EDORQUANTEISRION"
```

For each of 4 iterations: take `2*((w2 >> 8) & 31)` as an index into the table, emit that letter
pair, then `tweakseed`. **Bit 6 of the original w0** decides whether the name uses 3 or 4 pairs.
The `.` entries are null characters and are stripped, which is how names end up 2–8 letters long
(Lave, Diso, Leesti, Zaonce…). Lave is generated system #7 of galaxy 1 (`numforLave 7`).

This is the cheapest possible name generator and it produced a marketing-grade fictional universe;
the digram table doubles as the pronunciation model.

## 2. The commodity market model

Source: `genmarket()` and the `commodities[]` table in txtelite.c ("Data for DB's
price/availability generation system"). This is the authoritative published version of the 1984
market.

### 2.1 The formula

Each good has four constants: `baseprice`, `gradient` (signed, "five bits plus sign" in the 6502),
`basequant`, `maskbyte`. Each market visit rolls one random **fluctuation byte** `fluct`
(stored in the save file so prices are stable across saves). Then, per good, **all in 8-bit
arithmetic with deliberate overflow** ("overflow 'errors' are extremely frequent and exploited"):

```c
product  = economy * gradient;
changing = fluct & maskbyte;

quantity = (basequant + changing - product) & 0xFF;
if (quantity & 0x80) quantity = 0;          /* clip negative to zero  */
quantity &= 0x3F;                            /* cap at 63 units        */

price = ((baseprice + changing + product) & 0xFF) * 4;   /* internal   */
/* displayed price = internal / 10  =>  real price = byte * 0.4 Cr     */
```

Special rule: **Alien Items quantity is forced to 0** — they can never be bought, only sold
(combat/scooping loot has a market but no supply).

### 2.2 The commodity table (hex as in source; price step = 0.4 Cr)

| Good | base | gradient | basequant | mask | unit |
|---|---|---|---|---|---|
| Food | 0x13 | −2 | 0x06 | 0x01 | t |
| Textiles | 0x14 | −1 | 0x0A | 0x03 | t |
| Radioactives | 0x41 | −3 | 0x02 | 0x07 | t |
| Slaves | 0x28 | −5 | 0xE2 | 0x1F | t |
| Liquor/Wines | 0x53 | −5 | 0xFB | 0x0F | t |
| Luxuries | 0xC4 | +8 | 0x36 | 0x03 | t |
| Narcotics | 0xEB | +29 | 0x08 | 0x78 | t |
| Computers | 0x9A | +14 | 0x38 | 0x03 | t |
| Machinery | 0x75 | +6 | 0x28 | 0x07 | t |
| Alloys | 0x4E | +1 | 0x11 | 0x1F | t |
| Firearms | 0x7C | +13 | 0x1D | 0x07 | t |
| Furs | 0xB0 | −9 | 0xDC | 0x3F | t |
| Minerals | 0x20 | −1 | 0x35 | 0x03 | t |

Gold/Platinum/Gems are sub-tonne units — they don't consume hold space (`units != tonnes` skips
the holdspace checks in `gamebuy`/`gamesell`), making them the high-value-density smuggler's cargo.

### 2.3 Emergent trade lanes

Economy 0 = Rich Industrial, 7 = Poor Agricultural, and `product = economy × gradient`:

- **Negative gradient** (Food, Textiles, Liquor, Furs, Slaves, minerals/metals): price *falls* and
  quantity *rises* as economy number rises ⇒ cheap and plentiful in Poor Agricultural, dear in
  Rich Industrial.
- **Positive gradient** (Computers, Machinery, Luxuries, Firearms, Narcotics): cheapest/most
  available at Rich Industrial (economy 0, where `product = 0`), price grows by `gradient × economy`
  towards Poor Agricultural.

Worked example, Computers (base 0x9A = 154, gradient +14, mask 0x03 so fluctuation is tiny):
Rich Ind price ≈ 154×0.4 ≈ **61.6 Cr**, Poor Agri price ≈ (154+98)×0.4 ≈ **100.8 Cr** — ~39 Cr/t
margin. Furs on the return leg: Poor Agri ≈ (176−63+chg)×0.4 ≈ 45–70 Cr (mask 0x3F makes furs
volatile), Rich Ind sells ≈ 70 Cr. Hence the canonical loop the entire game economy funnels players
into: **Computers out from Rich Industrial, Furs/Liquor/Food back from Poor Agricultural**, ideally
between two close systems (Lave–Leesti–Diso–Zaonce cluster in galaxy 1). Narcotics' +29 gradient
and huge 0x78 mask make it the high-variance gamble good (frequently quantity 0, price wildly
fluctuating via byte overflow) — which pairs with its illegality in the full game.

Design takeaways: a single scalar (economy 0–7) plus a signed slope per good yields legible,
learnable price geography; the fluctuation byte adds noise without destroying the signal; the
63-unit quantity cap forces multi-good baskets and stops one-good degenerate hauling; player
purchases visibly deplete local stock (quantity is mutated by `gamebuy` and persists until the next
jump regenerates the market with a fresh fluct byte).

Note: txtelite has no legality mechanic, but in the real game Slaves/Narcotics/Firearms flag you
Offender/Fugitive and attract police Vipers — risk-premium pricing enforced by gameplay, not by the
price formula.

## 3. Combat and progression

Sources: Mark Moxon's annotated disassembly — combat rank deep dive
(<https://elite.bbcelite.com/deep_dives/combat_rank.html>), main-loop spawning
(<https://elite.bbcelite.com/cassette/main/subroutine/main_game_loop_part_4_of_6.html>),
equipment price table (<https://elite.bbcelite.com/cassette/main/variable/prxs.html>).

### 3.1 Ship outfitting (Cobra Mk III, BBC cassette prices from the PRXS table)

| Item | Price | What it changed |
|---|---|---|
| Fuel | 0.2 Cr / 0.1 LY (14 Cr full tank) | jump range up to 7 LY |
| Missile (max 4) | 30 Cr | fire-and-forget kill; countered by enemy ECM |
| Large Cargo Bay | 400 Cr | hold 20t → 35t; directly multiplies trade income |
| Extra Pulse Laser | 400 Cr | fit a laser on rear/side views |
| E.C.M. System | 600 Cr | destroys incoming missiles |
| Extra Beam Laser | 1,000 Cr | much higher DPS, faster overheat |
| Fuel Scoops | 525 Cr | free fuel from sun-skimming + scoop cargo canisters (piracy income) |
| Escape Pod | 1,000 Cr | death insurance (lose cargo, keep ship/life) |
| Energy Bomb | 900 Cr | screen-clear panic button |
| Extra Energy Unit | 1,500 Cr | doubles energy recharge rate |
| Docking Computer | 1,000 Cr | automates docking (see §4) |
| Galactic Hyperdrive | 5,000 Cr | one-way jump to next galaxy |

Availability is tech-level-gated: the equipment list grows with system tech level (the cassette
`EQSHP` code computes roughly `TL + 3` items shown, capped at the full list of 12), so the Galactic
Hyperdrive and top gear only appear at high-TL worlds — an exploration incentive baked into the
shop. (Beware: the *Elite Players Guide* on elitehomepage.org lists somewhat different prices/TLs,
e.g. ECM 500, Beam 750; the PRXS table above is what the BBC cassette code actually charges.
Military lasers (~6,000 Cr) and Mining lasers (~800 Cr) only exist in the later disc/Master/enhanced
versions, not the original cassette release.)

Defence model: fore/aft **shields** recharge continuously from the **4 energy banks**; energy also
powers lasers and the ECM. Laser fire builds heat and cuts out when overheated (pulse = low heat,
beam = high DPS/high heat). This one shared energy pool is the entire combat resource economy —
every fight is an energy-management problem, and the Extra Energy Unit is the single biggest combat
power-spike in the game.

### 3.2 The rating ladder

Kills tracked in a 16-bit counter (`TALLY`); rank is a pure threshold function of it
(combat_rank deep dive):

| Rating | Kills |
|---|---|
| Harmless | 0–7 |
| Mostly Harmless | 8–15 |
| Poor | 16–31 |
| Average | 32–63 |
| Above Average | 64–127 |
| Competent | 128–511 |
| Dangerous | 512–2,559 |
| Deadly | 2,560–6,399 |
| **Elite** | **6,400+** |

Early 6502 versions: 1 ship = 1 kill. Later ports (BBC Master, Apple II, NES) introduced
**fractional kill points by ship type** (Anaconda 1.0, Cobra Mk III 0.9140625, Sidewinder
0.33203125), so easy kills stopped counting fully toward Elite. The near-geometric doubling of
thresholds is the progression genius: early ranks arrive fast (dopamine), Elite is a
thousands-of-kills marathon (prestige).

### 3.3 Encounter difficulty scaling

From the cassette main loop (part 4): each iteration an **EV ("extra vessels") counter** throttles
spawning (set 0 on system arrival, bumped on each spawn, decremented per loop — a pacing valve).
When eligible, there's a ~35% gate to attempt a hostile spawn, then the government check:

> "Reduce the random number in A to the range 0–7, and if A is less than the government of this
> system, jump to MLOOP to stop spawning." Anarchy (gov 0) skips the check entirely.

So **danger is proportional to `8 − government` in expectation**: Corporate States are nearly safe,
Anarchies are pirate-infested. Combined with §1.2's "Anarchy ⇒ poor economy" and §2's "poor agri =
cheap goods", the risk/reward loop closes by construction: the best buying prices live in the most
dangerous systems. Spawns are then split between pirate packs (up to 4, e.g. Sidewinders/Mambas),
lone bounty hunters (Mamba/Python/Cobra Mk III, aggressive AI, ~22% ECM-equipped), and rare
Thargoids; police Vipers hunt you when your legal status is Offender/Fugitive (smuggling
consequence). The cassette main-loop page documents government and randomness — not player rating —
as the spawn drivers; version differences exist across ports (some ports scale hostility with
score), so treat rating-scaled difficulty as **version-dependent, not core 1984**.

## 4. Docking

Source: docking checks deep dive (<https://elite.bbcelite.com/deep_dives/docking_checks.html>),
docking computer deep dive (<https://elite.bbcelite.com/deep_dives/the_docking_computer.html>).

The Coriolis station rotates continuously; its slot is a rectangle on the face nearest the planet.
Flying into the station runs five checks, and failing while touching the station = damage/death:

1. **Station not hostile** (bit 7 of the station's data byte 32 — shoot near the station and it is).
2. **Approach angle** within ~26° of the station's nose vector (`nosev_z_hi` vs 214 ≈ 96·cos 26°).
3. **Heading forward** into the slot (sign of z — approaching from behind fails).
4. **Inside a ~22° approach cone** from station centre (`z < 89` fails; cos t = 89/96).
5. **Roll match**: the slot must be within ~33.6° of horizontal on your screen
   (`|roofv_x_hi| ≥ 80`; cos t = 80/96) — i.e. you must rotate at the station's spin rate at the
   moment of entry.

Why this worked as design: docking is a *skill tax on every trade-loop iteration* — the game's
core money loop (buy → jump → dock → sell) ends in a 20-second execution test with death as the
failure mode. It converts trading from menu work into flying. And that is exactly why the
**docking computer is a meaningful upgrade** rather than a convenience toggle: 1,000 Cr (about 25
profitable tonnes of computers) buys removal of the most failure-prone step of the loop — an
earned "I've graduated from this minigame" moment. Notably it's priced at the same tier as the
beam laser/escape pod, i.e. the designers valued docking relief as highly as combat power.
(Bonus detail: in several versions auto-dock plays The Blue Danube — the 2001 joke.)

## 5. What the remakes changed

### 5.1 Oolite — the faithful lineage (wiki.alioth.net)

Oolite (2004–present) is explicitly "Elite '84 with the corners rounded". It **kept**: the 8×256
universe (renamed "sectors"), the digram names and classic charts, the 17-commodity market with the
same base/gradient/mask price system (exposed in `commodities.plist` / `trade-goods.plist` —
<https://wiki.alioth.net/index.php/Commodities.plist>), the 7 LY fuel limit, the rating ladder, and
the rotating-station docking geometry. Its economy page is frank that the model is still "the good
old 8-bit 42 KB Elite" single Rich-Ind ↔ Poor-Agri spectrum
(<https://wiki.alioth.net/index.php/Economics>).

What it **changed**, and why:

| Change | Why | seelite verdict |
|---|---|---|
| **Energy bomb removed** (1.77 moved it to strict mode only) | trivialized combat — one button killed everything on screen | **Adopt the removal** — don't ship a win-button |
| **Docking made more forgiving** + optional docking-clearance protocol; docking computers common and cheap | 1984 tolerances (26°/22°/33.6° + instant death) are brutal on modern expectations; the *skill* is worth keeping, the punishment level isn't | **Adopt**: keep manual docking, widen tolerances, make failure damaging rather than always lethal |
| **Fairness doctrine**: NPCs get the same ships, weapons, and rules as the player (Aegidian's founding design principle) | 1984 NPCs were fake (no real economy/equipment); symmetry makes the world credible | **Adopt** as a core principle |
| **Torus drive** (fast-forward travel between planet and station) replacing pure time-skip | in-system travel is dead time | Adopt *some* time-compression; note the wiki's own criticism — NPCs can't use the Torus drive, so it breaks the fairness rule and lets players cheese pursuits |
| Separate fore/aft shield model, laser heat, fuel injectors, scriptable AI, market regeneration over time | depth without changing the underlying formulas | Cherry-pick: laser heat and shield clarity are cheap wins |
| OXP mod ecosystem, missions/contracts layer | longevity | Out of scope for core, but keep data-driven tables (Oolite proved plists/JSON for commodities & ships pays off) |

### 5.2 Pioneer — the divergent lineage

Pioneer (2006–present) is **not** an Elite '84 remake: it recreates *Frontier: Elite II* (1993) —
realistic Newtonian flight, a full procedurally-generated Milky Way with orbital mechanics, seamless
planetary landings, autopilot-by-default (Wikipedia: Frontier's Newtonian model means ships slide
on momentum; Pioneer was started by Tom Morton in 2006 to recreate Frontier's open-ended freedom —
<https://en.wikipedia.org/wiki/Frontier:_Elite_II>). The relevant lesson is negative: Frontier's
realism **killed both signature skill loops** — dogfights became jousting passes and docking became
"press autopilot". For a browser Elite-'84 game, Pioneer's divergences (Newtonian physics, real
galaxy scale, autopilot-first) are **divergences to ignore**. Its positive lesson: system economies
derived from generated system properties (not hand-authored) scale indefinitely — which Elite '84
already did with 6 bytes.

## 6. Adoption recommendations for seelite

1. **Adopt the 48-bit seed scheme verbatim** (three 16-bit words, `tweakseed`, `twist`, base seed
   `5A4A/0248/B753`). It's ~30 lines of TypeScript, gives byte-identical Lave/Diso/Zaonce, and is
   trivially testable against txtelite output (Lave = system 7, galaxy 1). Keep 8 galaxies × 256
   systems; keep the digram name generator including the `.`-stripping.
2. **Adopt `genmarket` exactly**, including the 8-bit overflow behaviour, `&0x3F` quantity cap,
   the per-visit fluctuation byte (persist it in the save), Alien Items sell-only rule, and the
   `kg/g` goods bypassing hold space. Do the arithmetic in explicit `& 0xFF` masks — the overflow
   is a feature (Narcotics volatility), not a bug.
3. **Adopt the correlation cascade** (gov → economy → tech → population/GDP) and the
   government-gated spawn rule (`rand 0–7 < government ⇒ no hostile spawn`, anarchy always
   eligible, EV-style pacing counter). This single mechanism *is* Elite's risk/reward geography.
4. **Adopt the rating ladder unchanged** (8/16/32/64/128/512/2560/6400) — consider Master-style
   fractional kill points per ship type so Sidewinder farming doesn't reach Elite.
5. **Keep manual docking as a skill loop** with the 1984 check structure (approach cone, forward
   heading, roll match) but Oolite-ified: wider tolerances, hull damage instead of instant death,
   and the docking computer as a mid-game ~1,000 Cr purchase that automates it. Don't make
   auto-dock free/default (the Pioneer lesson).
6. **Adopt Oolite's inherited fixes**: no energy bomb (or strict-mode only), NPC fairness (NPCs use
   player-identical ships/equipment/market — matches seelite's symmetric-AI principle), laser heat,
   data-driven commodity/ship tables.
7. **Ignore Pioneer's divergences**: no Newtonian flight model, no real-scale galaxy, no
   autopilot-first design.
8. **Keep the goat-soup planet descriptions** (seeded grammar from w1/w2 bytes) — cheapest
   flavour-per-byte in the whole design.

## Open questions

- **Which version is canon for combat content?** Cassette (no military/mining laser, no missions)
  vs disc/Master (military laser 6,000 Cr, missions, fractional kills). Recommendation: cassette
  economy + Master-style fractional kills + disc laser tiers, but this is a design choice to make.
- **Reachability**: with a 7 LY tank some systems/clusters can be poorly connected in some
  galaxies; decide whether to verify connectivity per galaxy (BFS over the 7 LY graph) and whether
  a fix (fuel donation, one-off long jump) is needed. Not verified against the real seed data yet.
- **Rating-scaled difficulty**: whether hostile spawn rate should also scale with player rating
  (some ports did; the BBC cassette main loop documented above does not). Needs a decision, not
  more research.
- **Legality system scope** (Offender/Fugitive, police Vipers, smuggling premium on
  Slaves/Narcotics/Firearms): core 1984 feature absent from txtelite; formulas for legal-status
  decay were not researched here — bbcelite.com has the details if seelite wants them.
- Direct fetch of `txtelite.c` from Ian Bell's own domain 404'd during this research; the richcarl
  mirror of v1.4 was used. Worth pinning a copy of the source into `docs/reference/` if licensing
  allows ("A competant games programmer should be able to produce equivalent functionality" — Bell
  published it precisely as a reference).
